# Image-generation prompts — Personajes y Lugares

> Prompts narrativos pensados para **Midjourney v6 / Flux / DALL·E 3**. Cada uno mezcla la información del MDX/JSON del proyecto con un anclaje de estilo coherente por era.

**Totales**: 163 personajes · 66 lugares

**Cómo usarlos**

1. Copiá el prompt completo (incluyendo `--ar 2:3 --style raw --v 6 --quality 2`).
2. Para DALL·E 3 / Flux quitá los flags `--*` (son syntax de Midjourney) y pasale el texto puro.
3. Si querés variantes, agregá al final: ` --chaos 15 --weird 50` (Midjourney).
4. Para retratos, generá 4 variantes y elegí la cara con mejor coherencia.
5. Guardá el archivo según la convención: `public/images/characters/{group}/{id}.{png|jpg}` ó `public/images/locations/{id}.jpg`.
