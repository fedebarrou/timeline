# Línea de Tiempo · Adán → Mahoma

Sitio web profesional de scrollytelling que compara los relatos de la Torá, la Biblia y el Corán desde Adán hasta Mahoma, ubicando cada evento en un mapa antiguo manuscrito.

## Stack

Astro · TypeScript · Tailwind · GSAP ScrollTrigger · Maplibre GL

## Desarrollo

```bash
npm install
npm run dev
```
